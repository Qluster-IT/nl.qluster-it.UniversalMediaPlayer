Explora los archivos de un servidor UPnP y envía sus URL a un altavoz o televisor mediante Flows de Homey.

Selecciona un archivo o carpeta en una tarjeta de Flow y conecta el disparador La URL de reproducción ha cambiado con la acción de tu altavoz que reproduce una URL. La aplicación busca la URL actual mediante la ruta guardada.

La aplicación no reproduce audio por sí sola. Conecta el disparador Reproducción detenida a la acción de pausa o detención de tu altavoz.

Foro de la comunidad: https://community.homey.app/t/43450
Para consultar la wiki y el manual, selecciona Visitar sitio web en Sitio web del desarrollador, en la página de la aplicación en Homey App Store.
