Parcourez les fichiers d’un serveur UPnP et envoyez leurs URL à une enceinte ou à un téléviseur à l’aide des Flows Homey.

Sélectionnez un fichier ou un dossier dans une carte de Flow, puis reliez le déclencheur URL de lecture modifiée à l’action de votre enceinte qui lit une URL. L’application retrouve l’URL actuelle à partir du chemin enregistré.

L’application ne lit pas le son elle-même. Reliez le déclencheur Lecture arrêtée à l’action de pause ou d’arrêt de votre enceinte.

Forum de la communauté: https://community.homey.app/t/43450
Pour consulter le wiki et le manuel, sélectionnez Visiter le site Web sous Site Web du développeur sur la page de l’application dans le Homey App Store.
