Sfoglia i file di un server UPnP e invia i loro URL a un altoparlante o a una TV tramite i Flow di Homey.

Seleziona un file o una cartella in una scheda Flow, quindi collega il trigger URL di riproduzione cambiato all’azione del tuo altoparlante che riproduce un URL. L’app cerca l’URL attuale usando il percorso salvato.

L’app non riproduce direttamente l’audio. Collega il trigger Riproduzione interrotta all’azione di pausa o stop del tuo altoparlante.

Forum della community: https://community.homey.app/t/43450
Per la wiki e il manuale, seleziona Visita il sito web sotto Sito web dello sviluppatore nella pagina dell’app nell’Homey App Store.
