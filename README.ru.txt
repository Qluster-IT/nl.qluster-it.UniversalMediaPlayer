Просматривайте файлы на UPnP-сервере и отправляйте их URL на колонку или телевизор через сценарии Homey Flow.

Выберите файл или папку в карточке Flow и подключите триггер URL воспроизведения изменился к действию колонки для воспроизведения по URL. Приложение находит актуальный URL по сохранённому пути.

Приложение не воспроизводит звук само. Подключите триггер Воспроизведение остановлено к действию паузы или остановки на колонке.

Форум сообщества: https://community.homey.app/t/43450
Вики и руководство доступны на странице приложения в Homey App Store: Сайт разработчика → Перейти на сайт.
