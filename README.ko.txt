UPnP 서버의 파일을 탐색하고 Homey Flow를 통해 파일 URL을 스피커나 TV로 보내세요.

Flow 카드에서 파일이나 폴더를 선택한 다음, 재생 URL이 변경됨 트리거를 스피커의 URL 재생 동작에 연결하세요. 앱은 저장된 경로를 기준으로 현재 URL을 찾습니다.

앱 자체에서는 오디오를 재생하지 않습니다. 재생이 중지됨 트리거를 스피커의 일시 정지 또는 중지 동작에 연결하세요.
